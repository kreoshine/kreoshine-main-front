#### Explanation
block is responsible for the style marking of nested elements:
- provides from one two three cards at row dependency on screen width

##### usage
.bemhtml.js
``` 
block: 'card-collection',
content: [
    {
        elem: 'item',
        content: {
            block: 'some-card',
        }
    },
```
